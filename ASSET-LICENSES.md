# Asset licenses

Every sprite in this repo comes from a pack whose license allows redistribution in a public repository. The license file of each pack is kept next to the sprites in `src/AncosSantiye/skins/<skin>/licenses/`.

Scaffolding, the tower crane, slabs, columns, the truck, the site office and the waybill board are simple shapes drawn in code.

## Custom skins

Packs that forbid redistribution can still be used locally: put them in your own skin folder outside the repo and point your profile at it. Do not commit them.
